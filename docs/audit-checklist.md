# Pre-Mainnet Checklist

- [ ] Complete an external audit and publish the final report.
- [ ] Run Slither and resolve or document all findings.
- [ ] Lock the DEX liquidity position and publish independent proof and unlock details.
- [ ] Place treasury control under a Safe Multisig with published signers and policies.
- [ ] Complete team KYC through an appropriate provider and document the result.
- [ ] Verify contract source on BscScan and publish all deployed addresses.
- [ ] Obtain legal review for the public sale in each relevant jurisdiction.
- [ ] Publish tokenomics, sale terms, vesting details, risk disclosures, and project documentation.
- [ ] Confirm the team vesting wallet is funded with only the approved allocation.
- [ ] Review deployment parameters, treasury ownership, and operational procedures before any mainnet transaction.
